# Greedy Clips

Free instant replay for Windows 10/11. Press a hotkey in any game and the last moments are saved,
sorted into a folder per game. No account, no paywall, no game hooks.

## Download

**[Get the latest GreedyClips-Setup.exe](https://github.com/Greedyvikas/greedy-clips-releases/releases/latest)**
(under *Assets*), run it, done.

- Windows may say "Windows protected your PC" the first time (the app isn't code-signed yet):
  click **More info → Run anyway**.
- Updates install themselves: Greedy Clips checks this page every few hours and shows
  **Update now** when there's a new version. Your clips and settings are kept.
